# 0.17.0 security-posture integration addendum

The authoritative 0.17.0 design consists of these component specifications:

- `2026-09-14-0.17.0-security-posture-design.md` — detailed Endpoint Security Posture design, including AV/EDR, firewall, Windows Update, UAC, TPM, VBS/HVCI, UX, hardening and release boundaries.
- `2026-09-14-0.17.0-firmware-storage-security-design.md` — owner-approved extension for BIOS/UEFI administrative password, internal-only firmware boot, and all applicable fixed-volume encryption.
- `2026-09-14-0.17.0-local-admin-policy-design.md` — owner-approved local Administrators allow-list control, machine Registry policy, ADMX/ADML management contract, `*`/`?` wildcard language and final revised 100-point allocation.

The firmware/storage component supersedes the original single `SEC-BITLOCKER` design and adds the firmware/storage controls. The local-admin component supersedes only the earlier weighted-control tables by adding `SEC-LOCAL-ADMINS` and rebalancing Endpoint Security Posture v1 back to exactly 100 points.

No later component removes or weakens the detailed evaluator, AV, firewall, Windows Update, Kaspersky, firmware/storage, hardening, localization, reporting or test requirements from earlier components unless it explicitly states the narrow requirement it supersedes.

The 0.17.0 implementation plan MUST read and implement all four files together (this addendum plus the three component design files). Where text conflicts, later component text controls only for its explicit subject and, for `2026-09-14-0.17.0-local-admin-policy-design.md`, the final 100-point weight allocation.
