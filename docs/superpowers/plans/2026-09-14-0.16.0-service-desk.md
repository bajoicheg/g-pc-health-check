# 0.16.0 Service Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship G PC Health Check 0.16.0 with bilingual RU/EN UX, human-readable MB file/folder sizes, safe Analysis auto-collection, About/branding improvements, a centralized Service Desk action registry, Select All, conservative green remediation, explicit red “Do everything” remediation, one-UAC phased elevation, and a verified 0.16.0 release.

**Architecture:** Keep one portable WinForms EXE. Add presentation/localization primitives, a code-owned action registry and batch planner, then extend the existing authenticated elevated worker behind injectable fixed Windows-operation handlers. Green/red/selected workflows share the same registry/preflight/result model; the red batch uses one session/nonce-bound worker lifetime with explicit phases so alternate-admin elevation never impersonates the interactive user and network disruption remains late.

**Tech Stack:** C# / .NET 8.0.425, WinForms, embedded .resx resources, System.Text.Json, System.Management, System.ServiceProcess.ServiceController, named pipes + `runas`, existing PowerShell branding/build tools, GitHub Actions Windows CI.

- `docs/superpowers/specs/2026-09-14-0.16.0-ui-localization-design.md`

## Global Constraints

- Keep one portable Windows x64 EXE; arbitrary valid EXE location/name remains supported.
- Preserve UAC, fixed worker allow-list, named-pipe session binding and nonce validation.
- Elevated read-only Temp preview remains allowed; actual Temp deletion remains verified same-user, same-session and non-elevated.
- Missing telemetry remains unknown/partial, never zero or healthy by implication.
- No raw/full SMART, broad system-handle enumeration, treemap or stress/stability workload in 0.16.0.
- Never disable, stop, uninstall, exclude, reconfigure or weaken antivirus, Defender, EDR/XDR, firewall or other protective software.
- No arbitrary PowerShell/CMD/script, arbitrary executable, arbitrary service name, arbitrary adapter name, Event Log clearing, credential/profile deletion, forced reboot or forced logoff.
- Hosted CI must not perform real disruptive repairs; native mutation tests use injected fakes/synthetic fixtures. Existing safe worker-negative and portable process tests stay enabled.
- Every implementation task follows test-first RED → minimal implementation → GREEN in Windows CI in this connector-only environment.
- Do not bump to 0.16.0 until the functional implementation is final-candidate GREEN.
- Do not merge unless immediately-before-merge refresh confirms current `main`, exact PR head, PR conversation comments, reviews and review threads are unchanged and unblocked.
