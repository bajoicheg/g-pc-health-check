# 0.15.1 validation record

## Release baseline

0.15.1 is a pilot maintenance release based on `main` commit `32ed022fcb9fa13598f0423d4d7ca123815b862b`, which is 47 commits ahead of released 0.15.0 commit `b3d56fed5a55a6c1591a04dc321521792bf4e8c6` before the version/documentation bump.

The release adds no new major product or remediation scope. It packages the already-reviewed maintenance fixes and the current pilot/evidence tooling into a versioned candidate.

## Automated validation required

Before merge, the exact final PR head must pass the existing required workflows, including:

- Windows EXE: restore, NuGet vulnerability audit, warnings-as-errors build, all source self-tests, published single-file EXE self-test, portable worker/security matrix, exact FileVersion/SHA-256 gate and pilot-bundle verification;
- E2E Evidence Analyzer;
- Supply Chain Smoke and any other required branch checks.

After merge, the fresh exact `main` commit must pass Windows EXE and Evidence Analyzer. The release and supply-chain workflows must then validate the same tested main build before publication/attestation.

## Manual acceptance boundary

Hosted CI is not managed Windows 11 acceptance. Pilot results remain NOT RUN until exercised on actual approved endpoints using [`docs/E2E-TEST-PLAN.md`](../E2E-TEST-PLAN.md), including UAC/alternate-admin, RDP, 100/150/200% DPI, corporate VPN/EDR and representative OEM/storage scenarios.

## Publication verification

Publication is complete only after `v0.15.1` exists for the exact tested main commit and the released EXE, checksum and pilot ZIP are present. The downloaded EXE bytes must be checked against the published SHA-256 before distribution.
