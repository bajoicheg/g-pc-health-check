# 0.15.1 — Pilot hardening maintenance release

## Purpose

0.15.1 packages the maintenance fixes accumulated after 0.15.0 into one pilot build. It deliberately keeps the 0.15.x product scope: this is a reliability, evidence-integrity and usability release, not a new-feature expansion.

## Included hardening

The maintenance line since 0.15.0 includes focused, regression-tested corrections in these areas:

- stale row/detail and target presentation across several read-only diagnostic windows;
- clear separation of next-run controls from the evidence already collected and still visible/saveable;
- ownership of progress callbacks so an older, cancelled or completed operation cannot overwrite a newer or terminal status;
- explicit cancellation and save/export failure terminal states instead of stale success/running text;
- Diagnostic Bundle save-thread affinity, saveable/visible snapshot alignment, execution-context/source selection, performance options, symptom-marker timing and progress ownership;
- Performance Session equal-boundary scheduling and wording that keeps unavailable/missed telemetry distinct from zero;
- managed Windows 11 pilot coverage for UAC, RDP, DPI, VPN/EDR and OEM/storage diversity;
- stricter E2E evidence analysis: an input containing more than one workstation evidence root is rejected instead of selecting an arbitrary root.

These fixes preserve the existing interpretation boundary: missing telemetry is not health, correlations are not causes, and a collection/export failure does not silently become success.

## Safety and product scope unchanged

0.15.1 does **not** add a new remediation action or broaden privileged execution. Existing invariants remain:

- one portable Windows x64 EXE, runnable from any valid local path and under any valid filename;
- existing UAC behavior and remediation worker allow-list;
- worker nonce/session binding;
- elevated read-only Temp preview remains allowed;
- Temp deletion remains limited to the verified same-user non-elevated context;
- no automatic upload or hidden elevation for read-only diagnostics.

Raw/full SMART, broad system-handle enumeration, treemap, stress/stability workloads and new remediation/rollback operations are not part of 0.15.1.

## Pilot acceptance

Use [`docs/E2E-TEST-PLAN.md`](../E2E-TEST-PLAN.md) for the managed Windows 11 pilot. Hosted Windows CI validates compilation, source and published-EXE self-tests, the portable/security matrix, FileVersion/checksum, pilot bundle construction and the automated evidence analyzer. It does not replace interactive Windows 11 acceptance for standard/elevated/alternate-admin sessions, UAC, RDP, 100/150/200% DPI, corporate VPN/EDR or representative OEM/storage providers.

For every pilot machine/session record the exact 0.15.1 EXE SHA-256, Windows build, device/session context and PASS/FAIL/N/A evidence before treating the pilot as accepted.

## Distribution

The release artifacts are expected to be:

- `G-PC-Health-Check.exe` — self-contained single-file Windows x64 application;
- `G-PC-Health-Check.exe.sha256` — SHA-256 checksum for the EXE;
- `G-PC-Health-Check-0.15.1-pilot.zip` — optional pilot/E2E kit.

The EXE remains unsigned with Authenticode unless signing is separately introduced and verified. Verify the published checksum/provenance before pilot distribution.
