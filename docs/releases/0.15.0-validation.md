## Boundaries and pilot limits

The 0.15.0 feature is orchestration/presentation around existing read-only collectors. It adds no remediation, active external probe, automatic elevation, upload or generic redaction route.

Hosted Windows CI is not corporate Windows 11/RDP/alternate-account/DPI/VPN/EDR acceptance. Provider cancellation is cooperative. No actual DISM/SFC/DNS flush/Temp deletion, third-party process termination or external host/port probe is part of the bundle test path. Authenticode remains absent unless separately introduced and verified.
