## Boundaries reviewed

The 0.15.0 feature is orchestration/presentation around existing read-only collectors. Final diff review must confirm no changes to remediation worker/allow-list/UAC/Temp deletion policy, no new dependency or workflow permission, no `ResourceProbeService` call from the coordinator, and no active probe or repair route exposed through `IDiagnosticBundleCollector`.

Hosted Windows CI is not corporate Windows 11/RDP/alternate-account/DPI/VPN/EDR acceptance. Provider cancellation is cooperative. No actual DISM/SFC/DNS flush/Temp deletion, third-party process termination or external host/port probe is part of the bundle test path. Authenticode remains absent unless separately introduced and verified.
